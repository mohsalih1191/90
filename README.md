# دوري المجتمع 90X - League 90X Platform

نظام ولوحة دوري مجتمعية مباشرة مبنية على رحلة 90X، تدعم تسجيل المشاركين، مراجعة المشرفين، احتساب النقاط العادل، والبث المباشر العمودي على تيك توك بنسبة 9:16.

---

## 🚀 استضافة وتشغيل التطبيق من GitHub مباشرة (GitHub Pages Host)

تم تضمين ملف سير عمل جاهز ومؤتمت (`.github/workflows/deploy.yml`) يقوم ببناء التطبيق ونشره تلقائياً على **GitHub Pages** بمجرد رفع الكود إلى المستودع.

### خطوات تفعيل الاستضافة (خلال دقيقة واحدة):

1. **ارفع الكود إلى مستودع GitHub الخاص بك (Push to GitHub):**
   ```bash
   git add .
   git commit -m "Initial commit - 90X League Platform"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPOSITORY_NAME.git
   git push -u origin main
   ```

2. **تفعيل ميزة GitHub Pages في المستودع:**
   - ادخل على صفحة المستودع في GitHub.
   - اضغط على **Settings** (الإعدادات).
   - من القائمة الجانبية، اختر **Pages**.
   - في قسم **Build and deployment**:
     - غيّر خيار **Source** من `Deploy from a branch` إلى **`GitHub Actions`**.

3. **النشر التلقائي:**
   - بمجرد اختيار `GitHub Actions` أو عمل أي `git push` جديد، سيبدأ مسار العمل تلقائياً تحت تبويب **Actions**.
   - خلال ثوانٍ سيظهر لك رابط الموقع الحي المباشر (مثل: `https://USERNAME.github.io/REPOSITORY_NAME/`).

## 🐳 تشغيل المشروع عبر Docker

إذا كنت ترغب باستضافته عبر أي خادم سحابي (VPS / Render / Railway / Cloud Run) باستخدام Docker:

```bash
# بناء الصورة
docker build -t 90x-league .

# تشغيل الحاوية
docker run -d -p 8080:80 --name 90x-app 90x-league
```
ثم افتح `http://localhost:8080`.

## ✨ المميزات الرئيسية للنظام

1. **واجهة المشارك (Participant View):**
   - تسجيل يومي مع احتساب درجات الـ 100 تلقائياً (مهام، استمرارية، تحسن، تفاعل).
   - مخطط بياني تفاعلي (Recharts) لآخر 30 يوماً وتتبع خط الأساس.
   - حماية وخصوصية الصور المرفوعة مع تشفير وإزالة بيانات EXIF والتعتيم التلقائي.

2. **واجهة المشرف والتحكم (Moderator/Admin View):**
   - طابور اعتماد ومراجعة التسجيلات مع إمكانية فك التعتيم المشروط للتحقق.
   - سجل تدقيق أمني غير قابل للتعديل (Tamper-Proof Audit Log).
   - دليل ومتابعة للأعضاء وتنبيه المتأخرين وتصدير البيانات بصيغة CSV.

3. **واجهة البث العام لتيك توك (TikTok Live 9:16 View):**
   - شاشة عمودية بنسبة 9:16 متوافقة مع شاشات الهواتف وبرامج OBS.
   - تباين عالي وخطوط واضحة سهلة القراءة.
   - ساحة المواجهات الأسبوعية وشريط الأخبار العاجلة دون كشف أي بيانات شخصية.
